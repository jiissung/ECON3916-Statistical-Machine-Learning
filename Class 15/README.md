The Polynomial Trap: Bias-Variance Tradeoff

This project investigates the bias-variance tradeoff through controlled experiments on synthetic and real-world data. Using Python, numpy, scikit-learn, and matplotlib, I constructed polynomial regression models of varying complexity to analyze how model flexibility impacts generalization performance. On synthetic sine-wave data (n=50 training, n=200 test), I demonstrated the classic overfitting pattern: low-degree models exhibited high bias, while high-degree models showed high variance. Complexity curves revealed that polynomial degrees 3–5 minimized test RMSE, balancing bias and variance effectively.

I implemented K-fold cross-validation to estimate out-of-sample performance and found that the cross-validation-selected degree closely matched the true test-optimal model, validating CV as a reliable model selection tool. Extending the analysis to the Ames Housing dataset (1,460 observations, 80 features), I compared a full “kitchen-sink” regression against a parsimonious model using the top five correlated features. Despite achieving a lower training R², the simpler model produced superior cross-validated RMSE, highlighting the risks of overfitting in high-dimensional settings.

Overall, this work demonstrates practical model selection strategies, emphasizing the importance of cross-validation and feature selection in building models that generalize well to unseen data.
